Configuração do Cue

Cadastre um servidor MCP por comando local com o programa e argumentos acima e defina o diretório de trabalho real do checkout no computador que executará o processo. O stdio local não exige Bearer; a conta ou computador do Cue precisa ter o código e Python 3 disponíveis.

Requisitos do Grok Bot

Configure uma URL MCP pública HTTPS e a autenticação Bearer no conector customizado. Será necessário hospedar o serviço atrás de TLS/proxy seguro, configurar o hostname permitido e guardar um segredo forte no ambiente do servidor. Isso é separado da API de modelos Grok/xAI.

Acesso de leitura e análise, sem gravação

O MCP lê código, regras e arquivos textuais permitidos do checkout, além do histórico que já exista no SQLite em modo somente leitura. Arquivos ocultos, bancos, credenciais e binários ficam excluídos; valores que parecem tokens/chaves são mascarados. Pode analisar jogos fornecidos na chamada e gerar prévias sem persistir. Não altera jogos ou estudos, aposta, opera contas, publica ou envia dados a terceiros. Jogos em localStorage de outro navegador não são acessíveis diretamente.

O modo HTTP continua exigindo Bearer forte, mantido apenas no ambiente seguro do servidor e no campo protegido do conector remoto; nunca aparece nesta página. O modo local stdio do Cue não usa Bearer.
